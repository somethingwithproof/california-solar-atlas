# California Solar Atlas

[![CI](https://github.com/somethingwithproof/california-solar-atlas/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/somethingwithproof/california-solar-atlas/actions/workflows/ci.yml)
[![License](https://img.shields.io/badge/license-MIT-blue)](../../../LICENSE)

Статический интерактивный обозреватель данных о распределённой солнечной энергетике по всем 483 инкорпорированным городам и всем 58 округам Калифорнии.

## Возможности

- Поиск по каждому инкорпорированному городу Калифорнии и просмотр всех 58 округов.
- Просмотр заявленной мощности постоянного тока (DC), диапазонов годовой выработки с поправкой на климатическую зону и год ввода, пятилетнего роста, категорий потребителей и количества объектов с накопителями энергии.
- Интерактивная картограмма штата с использованием официальных полигонов границ инкорпорированных городов.
- Рейтинги городов с фильтрами по численности населения, зоне обслуживания энергокомпании и почтовой географии, а также одновременное сравнение до четырёх городов.
- Постоянные ссылки на города и округа, экспорт в CSV и SVG, а также прозрачное описание ограничений данных.
- 45 локалей интерфейса (20 локалей Tier 1, 15 африканских и 10 азиатских) с автоматическим определением языка браузера, переключателем языка в шапке и поддержкой разметки RTL.

## Локализация

Строки интерфейса хранятся в `src/locales/` для 45 локалей. При загрузке приложение проверяет `?lang=`, `localStorage` и `navigator.languages` / `navigator.language`, а при отсутствии совпадений использует английский язык. Локали с письмом справа налево (`ar`, `ar-EG`, `ar-MA`, `fa`, `he`, `ur`) автоматически устанавливают `dir="rtl"`.

```bash
npm ci
npm run dev
npm test
npm run build
```
