# కాలిఫోర్నియా సోలార్ అట్లాస్

[![CI](https://github.com/somethingwithproof/california-solar-atlas/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/somethingwithproof/california-solar-atlas/actions/workflows/ci.yml)
[![License](https://img.shields.io/badge/license-MIT-blue)](../../../LICENSE)

కాలిఫోర్నియాలోని మొత్తం 483 ఇన్‌కార్పొరేటెడ్ నగరాలు మరియు మొత్తం 58 కౌంటీలలో నమోదైన పంపిణీ సౌరశక్తి కోసం ఒక స్టాటిక్, శోధించదగిన అన్వేషణి.

## విశిష్టతలు

- కాలిఫోర్నియాలోని ప్రతి ఇన్‌కార్పొరేటెడ్ నగరాన్ని శోధించండి మరియు మొత్తం 58 కౌంటీలను బ్రౌజ్ చేయండి.
- నమోదైన DC సామర్థ్యం, వాతావరణ-మండలం మరియు కాలమాన-సర్దుబాటు చేసిన వార్షిక ఉత్పత్తి శ్రేణులు, ఐదేళ్ల వృద్ధి, కస్టమర్ రంగాలు, మరియు నిల్వ-అనుసంధానిత సైట్ సంఖ్యలను వీక్షించండి.
- అధికారిక ఇన్‌కార్పొరేటెడ్-నగర బహుభుజులను ఉపయోగించే ఇంటరాక్టివ్ రాష్ట్రవ్యాప్త కోరోప్లెత్ మ్యాప్.
- జనాభా, యుటిలిటీ-కవరేజ్, మరియు మెయిలింగ్-భౌగోళిక ఫిల్టర్లతో నగర ర్యాంకింగ్‌లు, అలాగే నాలుగు నగరాల పక్కపక్కనే పోలిక.
- భాగస్వామ్యం చేయగల నగర మరియు కౌంటీ URL లు, CSV మరియు SVG ఎగుమతులు, మరియు పారదర్శక డేటా పరిమితులు.
- స్వయంచాలక బ్రౌజర్ భాషా గుర్తింపు, హెడర్ భాషా ఎంపిక, మరియు RTL లేఅవుట్ మద్దతుతో 45 ఇంటర్‌ఫేస్ లోకేల్స్ (20 టియర్ 1, 15 ఆఫ్రికన్, మరియు 10 ఆసియా లోకేల్స్).

## స్థానికీకరణ

ఇంటర్‌ఫేస్ స్ట్రింగ్‌లు 45 లోకేల్స్‌లో `src/locales/` లో ఉంటాయి. లోడ్ అయ్యేటప్పుడు, యాప్ `?lang=`, `localStorage`, మరియు `navigator.languages` / `navigator.language` లను తనిఖీ చేసి, అవి లేకపోతే ఆంగ్లానికి మారుతుంది. RTL లోకేల్స్ (`ar`, `ar-EG`, `ar-MA`, `fa`, `he`, `ur`) స్వయంచాలకంగా `dir="rtl"` ను సెట్ చేస్తాయి.

## స్థానికంగా అమలు చేయండి

```bash
npm ci
npm run dev
npm test
npm run build
```
