# California Solar Atlas

[![CI](https://github.com/somethingwithproof/california-solar-atlas/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/somethingwithproof/california-solar-atlas/actions/workflows/ci.yml)
[![License](https://img.shields.io/badge/license-MIT-blue)](../../../LICENSE)

เครื่องมือสำรวจข้อมูลแบบคงที่ที่ค้นหาได้สำหรับระบบพลังงานแสงอาทิตย์แบบกระจายตัวที่มีการรายงานครอบคลุมทั้ง 483 เมืองที่จดทะเบียนจัดตั้งและทั้ง 58 เทศมณฑลในรัฐแคลิฟอร์เนีย

## ความสามารถ

- ค้นหาทุกเมืองที่จดทะเบียนจัดตั้งในรัฐแคลิฟอร์เนียและเลือกดูทั้ง 58 เทศมณฑล
- ดูข้อมูลกำลังการผลิต DC ที่รายงาน ช่วงการผลิตไฟฟ้าประจำปีที่ปรับตามเขตภูมิอากาศและปีที่ติดตั้ง การเติบโตในช่วงห้าปี กลุ่มผู้ใช้ไฟฟ้า และจำนวนสถานที่ที่เชื่อมต่อระบบกักเก็บพลังงาน
- แผนที่โคโรเพลทเชิงโต้ตอบทั่วทั้งรัฐโดยใช้รูปหลายเหลี่ยมขอบเขตเมืองอย่างเป็นทางการ
- การจัดอันดับเมืองพร้อมตัวกรองจำนวนประชากร พื้นที่ให้บริการสาธารณูปโภค และภูมิศาสตร์ทางไปรษณีย์ รวมถึงการเปรียบเทียบสี่เมืองแบบเคียงข้างกัน
- URL สำหรับแชร์ข้อมูลเมืองและเทศมณฑล การส่งออกไฟล์ CSV และ SVG และการแสดงข้อจำกัดของข้อมูลอย่างโปร่งใส
- ส่วนติดต่อผู้ใช้รองรับ 45 ภาษาท้องถิ่น (ภาษาท้องถิ่นระดับ Tier 1 จำนวน 20 ภาษา แอฟริกา 15 ภาษา และเอเชีย 10 ภาษา) พร้อมการตรวจจับภาษาของเบราว์เซอร์อัตโนมัติ ตัวเลือกภาษาบนส่วนหัว และการรองรับเลย์เอาต์แบบขวาไปซ้าย (RTL)

## การรองรับภาษาท้องถิ่น

ข้อความส่วนติดต่อผู้ใช้ทั้งหมดอยู่ใน `src/locales/` ครอบคลุม 45 ภาษาท้องถิ่น เมื่อโหลดแอป ระบบจะตรวจสอบ `?lang=`, `localStorage` และ `navigator.languages` / `navigator.language` หากไม่พบจะใช้ภาษาอังกฤษเป็นค่าเริ่มต้น ภาษาท้องถิ่นที่เขียนจากขวาไปซ้าย (`ar`, `ar-EG`, `ar-MA`, `fa`, `he`, `ur`) จะตั้งค่า `dir="rtl"` โดยอัตโนมัติ
