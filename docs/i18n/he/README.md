# אטלס האנרגיה הסולארית של קליפורניה

[![CI](https://github.com/somethingwithproof/california-solar-atlas/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/somethingwithproof/california-solar-atlas/actions/workflows/ci.yml)
[![רישיון](https://img.shields.io/badge/license-MIT-blue)](../../../LICENSE)

סייר סטטי ובר-חיפוש לנתוני אנרגיה סולארית מבוזרת מדווחת בכל 483 הערים המאוגדות בקליפורניה ובכל 58 המחוזות.

## תכונות

- חיפוש בכל עיר מאוגדת בקליפורניה ועיון בכל 58 המחוזות.
- צפייה בהספק DC מדווח, טווחי ייצור שנתיים מותאמים לאזור אקלים ולשנתון התקנה, צמיחה של חמש שנים, מגזרי לקוחות ומספרי אתרים המקושרים לאגירה.
- מפת כורופלת אינטראקטיבית ברמת המדינה המבוססת על מצולעים רשמיים של ערים מאוגדות.
- דירוגי ערים עם מסנני אוכלוסייה, כיסוי חברות חשמל וגאוגרפיית דיוור, וכן השוואה של ארבע ערים זו לצד זו.
- כתובות URL הניתנות לשיתוף עבור ערים ומחוזות, ייצוא ל-CSV ול-SVG, ופירוט שקוף של מגבלות הנתונים.
- 45 אזורי שפה לממשק (20 אזורי Tier 1, 15 אזורים אפריקאיים ו-10 אזורים אסייתיים) עם זיהוי אוטומטי של שפת הדפדפן, בורר שפה בכותרת ותמיכה בפריסת RTL.

## לוקליזציה

מחרוזות הממשק נשמרות תחת `src/locales/` עבור 45 אזורי שפה. בעת הטעינה, היישום בודק את `?lang=`, `localStorage` ואת `navigator.languages` / `navigator.language`, וחוזר לאנגלית כברירת מחדל. אזורי שפה הנכתבים מימין לשמאל (`ar`, `ar-EG`, `ar-MA`, `fa`, `he`, `ur`) מגדירים אוטומטית `dir="rtl"`.
