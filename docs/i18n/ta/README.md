# கலிபோர்னியா சூரிய சக்தி நிலப்படத் தொகுப்பு

[![CI](https://github.com/somethingwithproof/california-solar-atlas/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/somethingwithproof/california-solar-atlas/actions/workflows/ci.yml)
[![License](https://img.shields.io/badge/license-MIT-blue)](../../../LICENSE)

கலிபோர்னியாவின் இணைக்கப்பட்ட 483 நகரங்கள் மற்றும் 58 மாவட்டங்களில் பதிவான பரவலாக்கப்பட்ட சூரிய சக்திக்கான நிலையான, தேடக்கூடிய ஆய்வகம்.

## அம்சங்கள்

- கலிபோர்னியாவின் இணைக்கப்பட்ட ஒவ்வொரு நகரத்தையும் தேடி, அனைத்து 58 மாவட்டங்களையும் உலாவவும்.
- பதிவான DC திறன், காலநிலை மண்டலம் மற்றும் நிறுவல் ஆண்டுக்கு ஏற்பச் சரிசெய்யப்பட்ட வருடாந்திர மின் உற்பத்தி வரம்புகள், ஐந்தாண்டு வளர்ச்சி, வாடிக்கையாளர் துறைகள் மற்றும் சேமிப்புடன் இணைக்கப்பட்ட தள எண்ணிக்கைகளைக் காண்க.
- அதிகாரப்பூர்வ இணைக்கப்பட்ட நகரப் பல்கோணங்களைப் பயன்படுத்தும் ஊடாடும் மாநில அளவிலான வண்ணப்பட வரைபடம்.
- மக்கள்தொகை, மின்சார சேவைப் பரவல் மற்றும் அஞ்சல் புவியியல் வடிப்பான்களுடன் கூடிய நகரத் தரவரிசைகள், மேலும் நான்கு நகரங்களின் பக்கவாட்டு ஒப்பீடு.
- பகிரக்கூடிய நகர மற்றும் மாவட்ட URL கள், CSV மற்றும் SVG ஏற்றுமதிகள் மற்றும் வெளிப்படையான தரவு வரம்புகள்.
- தானியங்கி உலாவி மொழி கண்டறிதல், தலைப்பு மொழித் தேர்வி மற்றும் RTL தளவமைப்பு ஆதரவுடன் 45 இடைமுக மொழியிடங்கள் (20 Tier 1, 15 ஆப்பிரிக்க மற்றும் 10 ஆசிய மொழியிடங்கள்).

## உள்ளூர்மயமாக்கல்

இடைமுகச் சரங்கள் 45 மொழியிடங்களிலும் `src/locales/` இல் உள்ளன. ஏற்றப்படும்போது, பயன்பாடு `?lang=`, `localStorage` மற்றும் `navigator.languages` / `navigator.language` ஆகியவற்றைச் சரிபார்த்து, இல்லையெனில் ஆங்கிலத்திற்குத் திரும்புகிறது. RTL மொழியிடங்கள் (`ar`, `ar-EG`, `ar-MA`, `fa`, `he`, `ur`) தானாகவே `dir="rtl"` ஐ அமைக்கின்றன.

## உள்ளூரில் இயக்க

```bash

npm test
npm run build
```
