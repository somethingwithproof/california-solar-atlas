# Security policy

## Supported version

The deployed GitHub Pages site and the current `main` branch are supported. Older commits and locally modified copies are not maintained releases.

## Report a vulnerability

Please report security vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/somethingwithproof/california-solar-atlas/security/advisories/new). Do not include exploit details, personal information, or secrets in a public issue.

Include the affected URL or commit, reproduction steps, impact, and any suggested mitigation. You should receive an acknowledgement within seven days. Public data-quality and methodology problems that do not expose users or systems may be filed in the [public issue tracker](https://github.com/somethingwithproof/california-solar-atlas/issues/new).
